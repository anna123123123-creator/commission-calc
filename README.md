# 分销佣金计算器 · Commission Calculator

**[在线体验 →](https://anna123123123-creator.github.io/commission-calc/)**

免费开源、纯浏览器运行的分销佣金计算工具。输入商品售价、成本价和一级、二级分销佣金比例，自动算出各级分销商能拿到多少佣金，以及平台最终净利润——如果佣金比例设置过高导致亏本，会用红色明确提示。纯前端计算，不联网。

![screenshot](screenshot.png)

## 试用方法

直接用浏览器打开 `index.html`，或用静态文件服务器跑起来：

```bash
python3 -m http.server 8000
```

## 计算公式

```
一级分销佣金 = 售价 × 一级佣金比例
二级分销佣金 = 售价 × 二级佣金比例（可关闭）
平台净利润 = 售价 - 成本价 - 一级佣金 - 二级佣金
```

净利润为负时会用红色高亮，提醒佣金比例设置过高。
